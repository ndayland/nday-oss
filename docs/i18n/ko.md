## 1. 독자와 문체

취약점 관리·패치 담당자, 관제(SOC)·침해사고 대응, 보안 연구자. 평소 KISA 보호나라
보안공지, 벤더 보안 권고, CISA KEV, 보안뉴스·데일리시큐 기사를 읽는 사람들이다.
영어나 중국어 문안을 옮기지 않고, 각 메시지의 의도(keys.json)를 보고 한국 실무 문서처럼 썼다.

문체는 세 가지로 나눈다.

| 위치 | 문체 | 예 |
| --- | --- | --- |
| 생성 문장(상태 문단, 이벤트 문장, 피드 요약) | 개조식 명사형 종결 + 마침표. KISA 보안공지 개요("… 보안 업데이트 발표", "… 업데이트 권고")와 같은 방식 | `CVE 공개 5일 후 KEV 등재.` `CISA KEV 미등재.` |

- 독자를 부르지 않는다("귀하", "여러분" 없음). 권유는 "-하세요"까지만 쓴다(검색어를 좁히세요).

- 첫 페이지 이름은 "최근 변동". 인기 순위가 아니라 단계가 바뀐 취약점 목록이라는 뜻이 드러나는 표현이다. "핫", "트렌딩", "방금 움직인"은 쓰지 않았다.

## 4. 표기 규칙

- 문장부호는 ASCII. 생성 문장과 합니다체 문장 모두 `.`로 끝낸다.
- 괄호: 한글 단어 바로 뒤에는 붙여 쓴다(`거부(REJECTED)`, `영향 제품`). 라틴 토큰·자리표시자 뒤에서는 한 칸 띄운다(`{time} ({precision})`, `{module} ({title})`). 단 `CVSS {score}(치명적)`는 점수와 등급을 한 덩어리로 보이게 붙였다.
- 원문 제목 인용은 “ ”(한국어 출판 관행).
- 목록: 산문은 `a, b 및 c`(`list.and.*`), 압축 목록은 `a, b, c`. "와/과"는 앞말 받침에 따라 바뀌므로 쓰지 않는다.
- 요일은 `2026-11-09 (월)`. 한국 달력·로그에서 쓰는 괄호 형식.
- 숫자는 `45,965`. 단위 명사: 건(이벤트·검색 결과), 곳(출처), 개(제품·버전), 일(날짜 수).
- 띄어쓰기는 표준어 규정을 따른다(`보여 줍니다`, `알 수 없음`).

### 자리표시자 뒤 조사

은/는, 이/가, 을/를, 와/과, (으)로는 앞말 받침에 따라 형태가 바뀌므로, 자리표시자 바로 뒤에는 붙이지 않았다. 쓰는 방법은 셋이다.

1. 콜론이나 괄호 뒤에 값을 둔다: `해결 버전: {versions}.`, `CVE 레코드 공개(CNA: {assigner}).`, `{id}: 데이터베이스에 없음`, `{minus}: CVE 레코드 공개 20일 전에…`
2. 고정 명사를 사이에 넣는다: `{since} 범위를`, `{min_stage} 기준을`, `{code} 시점은 날짜 단위`, `{itw} 단계도`
3. 받침과 관계없는 조사만 쓴다: 에서(`{source}에서 … 보고.`), 에(`{date}에`, `“{query}”에 해당하는`), 처럼(`{prefix2}처럼`), 의, 도

받침에 따라 바뀌는 조사가 자리표시자 바로 뒤에 붙은 메시지는 없다. 고정 리터럴 뒤 조사(`nday는`, `GHSA`, `400을`, `Esc 키로`)는 발음 기준으로 맞게 썼다.

## 5. 남은 문제

- **줄바꿈(CSS)**: 본문이 음절 단위로 끊긴다("매시/간", "포함합/니다"). 한국어 본문에는 `:lang(ko) { word-break: keep-all; }`이 필요하다. 템플릿·CSS는 담당 범위 밖이라 고치지 않았다(390px, 1440px 모두에서 확인).
- `tplus.title.after`에 0일이 들어오면 "공개 0일 후"가 된다(T+0d). 복수형 규칙이 `none`이라 0을 따로 처리할 수 없다. "공개 당일"을 쓰려면 별도 키가 필요하다.
- `status.lead.*`: "CVE 공개 1일 후"는 자연스럽지만, 기사체라면 "공개 다음 날"이라고 썼을 것이다. 숫자 하나로 처리하는 구조라 그대로 두었다.
- CVSS "치명적" 대 "긴급": 언론은 둘 다 쓴다. 벤더 등급(MS 긴급/중요)과 섞이지 않게 "치명적"을 택했다. 원어민 편집자 확인 필요.
- `ev.kev.added`: 등재 사실과 기한·점검 요구를 두 문장으로 나눴다(개조식). 한 문장으로 합치면 "등재(조치 기한: …)하고 … 요구"처럼 어색해진다.
- `nav.*`: 한국어 단어를 덧붙여 390px에서 메뉴가 두 줄이 된다(zh-Hans도 같다). 경로만 남길지는 편집자가 결정할 일이다.
- `src.backfill.state_at`의 "materialized state"는 한국어 대응어("구체화 상태")가 낯설어 영문을 괄호로 남겼다.
- `fact.tplus_note_day`: "{code} 시점은 날짜 단위"는 조사 문제를 피하려고 "시점은"을 넣은 형태다.
